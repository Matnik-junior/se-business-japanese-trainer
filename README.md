## 📖 About This Application

This program helps you practice Japanese used in business settings, especially tailored for software engineers (SE) in entry-level roles. It runs on your Windows computer without needing the internet. You can use real workplace scenarios to learn how to communicate clearly and professionally in Japanese.

The app focuses on spoken and written communication you might face in daily work, such as meetings, emails, and calls. It works like a trainer and roleplay partner. This makes your study practical and useful for real situations.

## 🔎 Key Features

- **Local-first design:** Work offline without sending your data anywhere.
- **Realistic roleplay:** Practice conversations as if you were in an SE workplace.
- **Entry-level focus:** Covers common business topics for new employees.
- **Japanese communication:** Includes polite and formal expressions used at work.
- **Easy to use:** No programming or technical skills needed.
- **Data stored locally:** Your progress is saved on your computer using SQLite database.
- **Built with Python and FastAPI:** Uses robust technology behind the scenes.
- **LLM-ready:** Supports integration with language models if you want advanced features.

The app shows simple menus. Here's how to start practicing Japanese:
